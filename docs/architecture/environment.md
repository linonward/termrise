# Environment Contract

## Environment Contract

`packages/config/src/env.ts` 的 `serverEnv()` 首次调用时解析并缓存服务端变量，缺失或格式错误抛出 `EnvError`。校验是惰性的，`apps/web/src/instrumentation.ts` 不执行环境校验；构建成功不能证明运行环境完整。

本地变量放在 `apps/web/.env.local`（不提交）：Next.js 从这里读取；`packages/db/drizzle.config.ts` 和测试数据库工具（`packages/db/src/testing/test-database.ts`）在没有对应环境变量时也读取这个文件。模板见仓库根目录的 `.env.example`。空值（`KEY=`）视为未设置：可选变量取默认值，必填变量报缺失。

`BETTER_AUTH_SECRET` 至少 32 字符；`APP_URL`、`BETTER_AUTH_URL`、`SENTRY_DSN` 必须为 URL，`R2_ENDPOINT`、`NEXT_PUBLIC_POSTHOG_HOST` 设置时也必须为 URL；`DATABASE_URL` 必须以 `postgres://` 或 `postgresql://` 开头。Fake 模式仍要求认证、邮件、R2 与 Sentry 的基础字段通过格式校验，E2E 使用占位值。

| Variable                   | Scope           | Notes                                                                                                                                                                                                                                                                                                                                    |
| -------------------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VERCEL_ENV`               | server          | 可选 `production` / `preview` / `development`；`production` 时禁止任何 Fake Provider，并决定 Waffo 的模式（`production` → prod，其他 → test）。Waffo Key 的环境必须与这个模式一致，否则所有 webhook 返回 401                                                                                                                             |
| `ALLOW_FAKE_PROVIDERS`     | test            | 只能为 `1`。生产构建（`NODE_ENV=production`，包括 `next start` 和 Vercel Preview）默认禁止 Fake Provider，设置后才允许；E2E 在 `e2e-env.ts` 中设置。`VERCEL_ENV=production` 时无效                                                                                                                                                       |
| `APP_URL`                  | server          | 站点根 URL，用于回调地址、metadataBase、sitemap / robots 中的绝对 URL                                                                                                                                                                                                                                                                    |
| `DATABASE_URL`             | server          | Neon pooled 连接串；Production 与 Preview 由 Neon 集成注入，带 `sslmode=require`。`createDb` 把 `prefer` / `require` / `verify-ca` 改为 `verify-full`（pg 8 打印 SSL 警告，pg 9 会弱化 `require` 的语义），带 `uselibpqcompat=true` 时不改；本地为当前 worktree 的 `dev/{topic}` 分支。`pnpm db:migrate` 和 `pnpm admin:adjust` 也读取它 |
| `TEST_DATABASE_URL`        | test            | 仅测试使用，必须指向本地 Docker / CI PostgreSQL，见 [testing.md](testing.md)                                                                                                                                                                                                                                                             |
| `BETTER_AUTH_SECRET`       | server          |                                                                                                                                                                                                                                                                                                                                          |
| `BETTER_AUTH_URL`          | server          |                                                                                                                                                                                                                                                                                                                                          |
| `GOOGLE_CLIENT_ID`         | server          |                                                                                                                                                                                                                                                                                                                                          |
| `GOOGLE_CLIENT_SECRET`     | server          |                                                                                                                                                                                                                                                                                                                                          |
| `RESEND_API_KEY`           | server          |                                                                                                                                                                                                                                                                                                                                          |
| `EMAIL_FROM`               | server          | 发信地址                                                                                                                                                                                                                                                                                                                                 |
| `R2_ACCOUNT_ID`            | server          |                                                                                                                                                                                                                                                                                                                                          |
| `R2_ACCESS_KEY_ID`         | server          |                                                                                                                                                                                                                                                                                                                                          |
| `R2_SECRET_ACCESS_KEY`     | server          |                                                                                                                                                                                                                                                                                                                                          |
| `R2_BUCKET`                | server          | 按环境区分，见 [Storage](overview.md#storage)                                                                                                                                                                                                                                                                                            |
| `R2_ENDPOINT`              | server          | 可选，本地 S3 兼容服务的地址（`http://localhost:8333`，见 [Local Storage](storage.md#local-storage)）；未设置时使用 `https://{R2_ACCOUNT_ID}.r2.cloudflarestorage.com`。`VERCEL_ENV=production` 时禁止设置                                                                                                                               |
| `STORAGE_PROVIDER`         | server          | `r2` \| `fake`，默认 `r2`，Production 必须为 `r2`；`fake` 只用于 E2E，见 [testing.md](testing.md)                                                                                                                                                                                                                                        |
| `FAKE_STORAGE_DIR`         | test            | `STORAGE_PROVIDER=fake` 时必填，对象以文件形式存放的目录                                                                                                                                                                                                                                                                                 |
| `TASK_PROVIDER`            | server          | `example` \| `deepseek` \| `fake`，默认 `example`，Production 不得为 `fake`。`example` 是示例 Provider（反转文本），可以在 Production 运行；`deepseek` 经 AI SDK 调用 DeepSeek；新产品换成自己的 Provider，见 [tasks.md](tasks.md)                                                                                                       |
| `DEEPSEEK_API_KEY`         | server          | `TASK_PROVIDER=deepseek` 时必填                                                                                                                                                                                                                                                                                                          |
| `DEEPSEEK_MODEL`           | server          | `TASK_PROVIDER=deepseek` 时必填，DeepSeek 的模型名（`deepseek-flash` 或 `deepseek-v4-pro`）                                                                                                                                                                                                                                              |
| `PAYMENT_PROVIDER`         | server          | `waffo` \| `fake`，Production 必须为 `waffo`                                                                                                                                                                                                                                                                                             |
| `WAFFO_MERCHANT_ID`        | server          | Merchant ID（`MER_…`），名称以 `@waffo/pancake-ts` 文档为准                                                                                                                                                                                                                                                                              |
| `WAFFO_PRIVATE_KEY`        | server          | API Key 的 RSA 私钥（SDK 支持 PEM 或 Base64 DER）；Key 创建时绑定 test / prod。应用的 Waffo 模式由 `VERCEL_ENV` 决定，Key 必须与它一致；`pnpm waffo:products` 只按 Key 判断环境                                                                                                                                                          |
| `WAFFO_STORE_ID`           | server          | Store ID（`STO_…`）                                                                                                                                                                                                                                                                                                                      |
| `SENTRY_DSN`               | server          |                                                                                                                                                                                                                                                                                                                                          |
| `NEXT_PUBLIC_SENTRY_DSN`   | client          |                                                                                                                                                                                                                                                                                                                                          |
| `SENTRY_AUTH_TOKEN`        | build           | source maps 上传                                                                                                                                                                                                                                                                                                                         |
| `SENTRY_ORG`               | build           | Sentry org slug（source maps 上传）                                                                                                                                                                                                                                                                                                      |
| `SENTRY_PROJECT`           | build           | Sentry project slug（source maps 上传）                                                                                                                                                                                                                                                                                                  |
| `NEXT_PUBLIC_POSTHOG_KEY`  | client + server | PostHog project key（客户端在 build 时内联；服务端未设置时不发送事件）                                                                                                                                                                                                                                                                   |
| `PORT`                     | server          | 只用于 `apps/api`，默认 3001                                                                                                                                                                                                                                                                                                             |
| `ADMIN_USER_IDS`           | server          | 可以进入 `/admin` 的 user id，逗号分隔；未设置时没有管理员，见 [Admin Access](security.md#admin-access)                                                                                                                                                                                                                                  |
| `NEXT_PUBLIC_POSTHOG_HOST` | server          | 服务端事件的 PostHog 地址，默认 `https://us.i.posthog.com`；客户端经 `/ingest` 代理（`apps/web/next.config.ts`）                                                                                                                                                                                                                         |

`TASK_PROVIDER=deepseek` 时，`DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL` 必须存在且不能仅含空白。`PAYMENT_PROVIDER=waffo` 时，三个 `WAFFO_*` 变量必须存在且不能仅含空白；`fake` 模式不要求提供。`TASK_PROVIDER`、`PAYMENT_PROVIDER`、`STORAGE_PROVIDER` 为 `fake` 的规则：`VERCEL_ENV=production` 时一律禁止；其他生产构建（`NODE_ENV=production`，例如自托管、Vercel Preview、本地 `next start`）只有设置 `ALLOW_FAKE_PROVIDERS=1` 时才允许；开发和测试（`NODE_ENV` 为 `development` / `test`）允许。只按 `VERCEL_ENV` 判断不够：不在 Vercel 上部署时没有这个变量，而 Fake 支付 webhook 的签名是公开的常量，任何人都能伪造付款。`R2_ENDPOINT` 必须为 URL，`VERCEL_ENV=production` 时不能设置。校验错误只包含变量名和规则，不输出私钥。私钥解析与 API 鉴权由 Provider SDK 执行。

`.env.example` 提供应用配置模板，不含真实值；它不含 source maps 上传使用的 `SENTRY_ORG` / `SENTRY_PROJECT`。`VERCEL_ENV` 和 `VERCEL` 由 Vercel 注入（`VERCEL=1` 时才加载 Web Analytics 与 Speed Insights）；`CI` 由 GitHub Actions 注入，影响 Playwright 的重试和 Sentry 构建日志。测试使用的 `TEST_DATABASE_URL` 由 test harness 单独校验。此表不表示每个变量均由 `serverEnv()` 解析：客户端与构建变量在各自入口读取。

CI（`.github/workflows/ci.yml`）只设置 `TEST_DATABASE_URL`（`app_test_ci` / `app_test_e2e`）和 E2E 构建时内联的 `NEXT_PUBLIC_POSTHOG_KEY=phc_e2e_test`。E2E 的其余变量来自 `apps/web/tests/setup/e2e-env.ts`，都是占位值。

新增、删除或改名变量时，同时更新本文件的 [Environment Contract](#environment-contract)、`.env.example` 和 `packages/config/src/env.ts`。
