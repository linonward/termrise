# 词库（工具站选词）

词库为新的工具站选一个长青主词：月搜索量够、新站能排上去、需求不在下滑、能变现。研究项目找产品机会（[product.md](product.md)），词库只回答"这个词值不值得做一个工具站"。规则来自 keyword-lab 的选词 SOP，在两轮真实数据（2026-10-04、2026-10-31）中验证过。

## Rules

规则版本 `tool-site-v1`（`packages/research/src/pool-rules.ts`、`pool-trend.ts`）。硬性条件全部满足才是候选；软性条件用于排序。

| 条件 | 内容                                                                                                                                                                       | 判断方式                         |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| H1   | 美国月搜索量 ≥ 5,000                                                                                                                                                       | 自动                             |
| H2   | KD ≤ 29；没有 KD 时标为待查，以 H5 为准                                                                                                                                    | 自动                             |
| H3   | CPC ≥ 0.10 美元；没有 CPC 时为 `unsure`                                                                                                                                    | 自动                             |
| H4   | 能变现：能放广告或能收费                                                                                                                                                   | 维护者确认                       |
| H5   | 前 10 名中强对手 ≤ 3 个。强对手：网站每月自然流量估算 ≥ 50,000，且页面专门为这个词做（标题包含这个词的全部单词）                                                           | 自动                             |
| H6   | ① 近 12 个月最高月 / 最低月 < 3；② 近 12 个月比前 12 个月跌幅不超过 50%；③ 最近 3 个月比去年同期的变化，比种子词（基线）多跌不超过 20%。没有基线时用绝对值：跌幅不超过 30% | 自动（Google Trends，美国 5 年） |
| H7   | 合规：主流意图不是绕过验证、伪造证件、下载别人的版权内容等                                                                                                                 | 维护者确认                       |
| S1   | 月搜索量 ≥ 50 的变种数，越多越好                                                                                                                                           | 自动                             |
| S2   | CPC 越高越好                                                                                                                                                               | 自动                             |
| S3   | 前 10 名中内页越多越好                                                                                                                                                     | 自动                             |
| S4   | 有 AI 改造点                                                                                                                                                               | 维护者填写                       |

补充规则：

- **先查中段**：月搜索量 5,000 到 30,000 的词先查。头部词大多是品牌词和被 AI 直接回答的词。
- **合并说法**：搜索量、CPC 和 12 个月曲线完全相同的几种说法是同一个需求（DataForSEO 只给它们不同的 KD），合并为一行，保留以种子词结尾的说法，否则保留最短的。
- **自动排除**：线下服务和工作（near me、repair、jobs）、购物（buy、price、best）、下载别人的内容（youtube to mp3）。自动排除只是建议，由维护者确认。
- **快速上升**：最近 3 个月比去年同期涨 50% 以上的词，H6 ① 不通过时标为"上升"，不当作季节性，留作观察。
- **大类萎缩**：种子词本身跌超过 40% 时，标出"大类萎缩"，不淘汰。

## Statuses

| 状态        | 意思                                               | 下次检查                                                                                     |
| ----------- | -------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `new`       | 维护者加入，还没检查                               | 立刻                                                                                         |
| `queued`    | 初筛通过，等深查                                   | 立刻（下一轮先查）                                                                           |
| `candidate` | 自动判断的硬性条件全部通过                         | 14 天                                                                                        |
| `unsure`    | 数据不够（没有 CPC、趋势不到 24 个月）             | 7 天                                                                                         |
| `watch`     | 快速上升的词                                       | 1 天                                                                                         |
| `failed`    | 硬性条件不过                                       | 按原因：趋势（H6）90 天，搜索量（H1）180 天，强对手（H5）120 天；KD、CPC、变现、合规不再检查 |
| `excluded`  | 不是网页工具（自动排除经维护者确认，或维护者排除） | 不再检查                                                                                     |
| `selected`  | 维护者选定，去建站                                 | 不再检查                                                                                     |
| `dropped`   | 维护者放弃                                         | 不再检查                                                                                     |

维护者在页面上可以：选定候选词，放弃，排除，把排除、放弃或失败的词改回 `queued`，回答变现（H4）和合规（H7），填写 AI 改造点。变现或合规回答"不行"时，词改为 `failed`，不再检查。每个操作都记成一条检查。
